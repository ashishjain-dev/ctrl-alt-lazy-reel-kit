# Remotion + Three.js engine (optional)

Same `scenes.yaml`, rendered in React with [Remotion](https://www.remotion.dev) and 3D characters built from [Three.js](https://threejs.org) primitives (no model files).

> **Licence:** Remotion is free for individuals and small companies, but larger companies need a paid company licence. Read https://www.remotion.dev/license before using it at work. Three.js is MIT.

```bash
cd engines/remotion
npm install
npm run prep -- ../../examples/dialogue-skit/scenes.yaml   # -> public/reel.json, voices, music/SFX
npm run studio                                             # live preview in the browser
npm run render -- ../../out/skit.mp4
npm run cover  -- ../../out/cover.png
```

- **Music and SFX** are generated by the Pillow engine's `reelkit audio` (needs Python + `pip install -e engines/pillow`). Without Python, `prep` skips them and voices still play. `--no-audio` skips on purpose.
- **Headless Chrome:** Remotion downloads one on first render. On locked-down machines pass `--browser-executable=/path/to/chrome`. Servers without a GPU: add `--gl=swangle` (WebGL in software; slower).
- **Fonts:** CSS families from `brand.yaml > web_fonts` (default `Inter`, then DejaVu). Install them on the machine, or load web fonts in `src/Root.tsx`.
- Characters: `src/Character3D.tsx` (`Person3D`, `Bot3D`, `Blob3D`). Same names, look options and moods as the 2D versions; `prep` resolves presets and named characters from brand.yaml / scenes.yaml. (`shirt_icon` text is 2D-only for now.)
- Emoji use the system colour emoji font (built in on macOS/Windows; Linux: `apt install fonts-noto-color-emoji`).
